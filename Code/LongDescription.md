# Planboard

Planboard is a location-aware planning board for Cities: Skylines II. Create issues, notes, and ideas, keep them as list-only tasks, or attach them directly to places in your city.

## Highlights

- Create Issue, Note, and Idea entries.
- Attach entries to map points, districts, roads, and buildings.
- Track Open, Doing, and Done work with clear status icons.
- Organize work with priorities, built-in or custom categories, one preferred deadline calendar, search, filters, and sorting.
- Show map pins as compact icons or open sticky notes.
- Keep planning data inside the city save.

Planboard has no runtime mod dependencies and supports Cities: Skylines II 1.6.x.
